Magic in your browser, on your own server.

Playmat is an Arena-style client for the XMage rules engine. Play every card in any format against your friends or the AI, and host the whole table yourself.

Play

One click from intent to play.

Pick a deck and press Play. You're in a game against the AI in seconds, or send a friend an invite link and sit down together. Nobody has to learn a table system first.

  • Attack arrows, a visible stack and priority you can read at a glance
  • Smart auto-pass with stops you choose, and keyboard shortcuts
  • Practice mode: a goldfish opponent and any card into your hand or onto the battlefield
  • Spectating, match history and replays of finished games

Decks

Bring the decks you already have.

Paste a link from Archidekt, Moxfield or another deck site, drop a list or a .dck file, and it's on your shelf. Starter decks are waiting from the first sign-in, Commander ones included.

  • Full card search by name, type, rules text, colour, cost, rarity and set
  • Format checks, a mana curve and colour counts as you build
  • Booster draft, sealed, Jumpstart and constructed events, with AI players in empty seats

Career

A journey for one player, with a whole card pool to earn.

Start with a starter deck and a hundred coins. Win duels, open packs, fill your collection and graduate from every format's school.

  • CampaignFive colour paths, a boss at the end of each.
  • The AcademyA school for every format, from the rules to today's decks.
  • GauntletBuild from packs and climb eight bosses.
  • Sealed & draftOpen or draft a set, then play to three wins.
  • PuzzlesWin from a fixed position this turn.
  • Weekly challengeThe same decks for everyone, and a board.

61 achievements, boss portraits, school crests and sleeves, all painted for Playmat.

Everywhere

Desktop, tablet, or the couch.

The table reflows from a wide monitor down to a tablet in portrait. Install it as a web app, or build the Android app, which keeps every card picture it has shown on the device for the next game.

  • Any modern desktop browser
  • Tablets in landscape and portrait, fullscreen when installed
  • Android app built from the same code
  • English and Spanish

And everything XMage already does.

  • Multiplayer

    Commander, Brawl, Oathbreaker and free-for-all games for up to ten players.

  • Tournaments

    Swiss or elimination events with drafting, sealed pools and sideboarding.

  • Lobby

    Chat, players online, profiles and a table browser to join or watch any game.

  • Rules on the server

    Every rule and every hidden card is enforced server-side. A client can't cheat.

  • Accounts

    Optional sign-up with passwords, ratings, moderation and admin tools for public servers.

  • Accessible

    Visible focus, reduced motion respected, and state never shown by colour alone.

Host

Your table, your rules.

One Docker Compose stack runs everything. Point a domain at the machine, set a few values and start it. Players open the site and sign in; nobody installs anything.

  • xmagethe game server and its WebSocket bridge
  • webCaddy: automatic HTTPS, security headers, rate limits
  • imgcachea caching proxy for Scryfall card pictures
  • backupnightly dumps of the player databases

Also covered: private LAN servers with no domain, running behind another reverse proxy, Discord notifications for new tables, and capacity numbers. Read the deployment guide.

# get the code
git clone https://github.com/arcanite24/playmat.git
cd playmat

# set DOMAIN, XMAGE_ADMIN_PASSWORD, XMAGE_AUTH
cp ops/web/.env.example ops/web/.env

# build and start the stack
docker compose -f ops/web/docker-compose.yml up -d --build

Built on XMage.

The rules engine, tens of thousands of card implementations and the AI are the work of the XMage project and its contributors since 2010. Playmat merges XMage every month, so new sets and fixes arrive here too. Card pictures and data come from Scryfall.
